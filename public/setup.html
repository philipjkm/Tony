🎅 Real Santa voice

The built-in voice is free but sounds robotic. For a realistic Santa, connect a free ElevenLabs account (an AI voice service — nothing to install). Santa then speaks every announcement on the TV, in English or Danish. Each line is made once and saved on this computer, so repeats are free and fast. If the internet drops, the built-in voice takes over.

  1. Create a free account at elevenlabs.io. Then open API Keys (in the left menu or under your profile) → Create API key. Give it access to Text to Speech and Voices (read and write). Copy the key.
  3. Pick a Santa voice — press ▶ to hear a sample, then Use this voice.
  4. Optional: makes all level, break and rebuy lines ahead of time so they play instantly on game night.

🎅 Santa's notes about the players

Write fun facts or shout-outs about each player, one per line. When a player rebuys or goes out, Santa tells one they haven't heard yet, so nothing is repeated for the same person. When someone's own facts run out, Santa uses his own shout-outs. Write them the way Santa should say them, in Danish if the announcer speaks Danish.

Start a line with Rebuy: or Out: to use it only at that moment. Lines without a label can be used for either.
